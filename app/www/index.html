Device and security

Settings backup

A restore replaces all saved settings with the file. Passwords and keys that are blank in the file (a backup without them) keep their current values. Restoring a Wi-Fi network or password can disconnect the camera for a moment.

SIP intercom

An address in this list is trusted: on a LAN a source address can be forged, so use it only on a network you trust. Everyone else must give the camera password (user root).

A short press of the reset button dials. Callers other than the server are asked for the password of user root (the camera password). The microphone is on while SIP is enabled, also in the live stream. Needs a camera password; starts after Save.

Firmware update

The camera checks the file, writes it to flash, verifies it and restarts (about a minute; do not power it off). Settings are kept. A wrong kernel image can leave the camera unbootable (recovery needs the serial console), so flash kernels only from a source you trust. Build and verify images as described in BUILDING.md.

Diagnostics

Passwords and keys are removed from this view and from the download, network names are replaced by <network> and MAC addresses are shortened. Still look through the file before posting it anywhere.

Wi-Fi

In this mode the camera is at 192.168.4.1 and hands out addresses itself. Default password cv206setup: change it.

    IP address

    The gateway is needed to reach other networks; DNS is needed for names such as the time server or a SIP server. Pick an address outside the range your router hands out. If the address is wrong the camera cannot be reached any more: then hold the reset button for 5 seconds (it clears all settings) or use the UART.
